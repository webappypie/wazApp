# Bundled fonts

All fonts are licensed under the SIL Open Font License 1.1 (texts in `assets/licenses/`).
Source: https://github.com/google/fonts (directory `ofl/<family>/`), fetched 2026-10-24.

| Family | Files | Scripts used by WazApp |
|---|---|---|
| Hind | Regular, Bold | Devanagari + Latin (default Hindi fallback) |
| Tiro Devanagari Hindi | Regular | Devanagari + Latin (serif) |
| Kalam | Regular, Bold | Devanagari + Latin (handwritten) |
| Rozha One | Regular | Devanagari + Latin (display) |
| Poppins | SemiBold | Latin (+ Hind fallback for Devanagari) |
| Pacifico | Regular | Latin only (+ Hind fallback for Devanagari) |

Emoji use the platform colour-emoji font (not bundled).
