# Product Scope and Release Matrix

| Area | Priority | Release expectation |
|---|---|---|
| Startup, navigation, permissions, data safety | P0 | Fully working |
| Android user-authorized status discovery/save | P0 | Validated by OS/device; no bypasses |
| iOS Photos/Files import and share/export | P0 | Working; no private WhatsApp-folder claim |
| Local library, viewer, search, favourites, bulk actions | P0 | Working |
| Photo editor | P1 | Real edits and validated exports |
| Video editor | P1 | Supported edits and validated exports |
| Hindi/English status maker | P1 | Real templates and correct rendering |
| Private Folder | P1 | App-private storage, accurate security claims |
| Storage Manager | P1 | Accurate usage, warnings only, confirmed delete |
| WAPCentral notifications, ads, promotions | P1 | According to actual guide |
| Remove Ads purchase/restore | P1 | Real store flow and entitlement |
| Cloud backup, social feed, cloud AI | Out of scope | Do not implement |

**Definition of done:** no feature is complete based on UI appearance alone. Demonstrate actual data flow, persistence, permissions, failure handling and test evidence.
