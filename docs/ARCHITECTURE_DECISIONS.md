# Architecture Decision Log

For each material decision create an ADR with: ID/title, status, context, decision, alternatives, trade-offs, migration plan and tests/evidence.

Explicitly assess: existing framework/state management (keep if sound); database and migrations; Android user-granted status access; iOS Photos/Files and share sheet; actual media processing/codec support; documented WAPCentral adapter; official store billing and product IDs; Private Folder security claims. Record decisions in `docs/adr/`.
