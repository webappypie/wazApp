# WazApp Implementation Roadmap

## Phase 0 — Audit and technical validation
Inspect repo/git, architecture, dependencies, Firebase filenames and full WAPCentral guide. Run baseline checks. Create audit/feature matrix and safe implementation plan. **Gate:** evidence-based baseline report.

## Phase 1 — P0 core saver and library
Fix startup/navigation/data issues; implement Android user-authorized access and iOS Photos/Files import/share; complete library/viewer/search/favourites/bulk actions, progress/errors, metadata and output validation. **Gate:** end-to-end core flows tested.

## Phase 2 — Photo editor and Status Maker
Real non-destructive photo edits/export; undo/redo; distinct Hindi/English templates and verified text rendering. **Gate:** output files validated.

## Phase 3 — Video editor
Supported trim/crop/mute/overlays, background encoding, progress/cancel/retry and output validation. **Gate:** representative exports play correctly.

## Phase 4 — Private Folder and Storage Manager
App-private storage, optional device auth, accurate storage totals, duplicate warnings and confirmed deletion. **Gate:** privacy/destructive-action tests pass.

## Phase 5 — WAPCentral, ads, promotions, notifications and billing
Follow actual guide, use test ads and billing sandbox, verify offline fallback and premium suppression. **Gate:** integration matrix evidenced.

## Phase 6 — Release hardening
Performance, accessibility, device matrix, privacy/legal review, release signing/build and final evidence. **Gate:** checklist complete or exceptions owner-approved.

Run tests after each coherent change. Do not mark a phase done without evidence.
