# Quick Start for Coding Agent

1. Read `AI_AGENT_HANDOFF.md` and `prompts/MASTER_AGENT_PROMPT.md`.
2. Inspect root, git status and existing project files; don't overwrite user changes.
3. Locate exact Firebase config filenames and WAPCentral guide filename.
4. Read WAPCentral guide completely before integration work.
5. Run baseline analyzer/tests/builds and create `docs/audit/BASELINE_AUDIT.md`.
6. Create `docs/audit/FEATURE_MATRIX.md` with evidence for each feature.
7. Fix P0 correctness/privacy/data integrity first, then follow `docs/PHASE_ROADMAP.md`.
8. Run tests after each phase; update logs and limitations.
9. Finish with `docs/RELEASE_CHECKLIST.md` and factual report.

Never fabricate test results, print secrets, delete/reinitialize the project, or claim device-level verification that did not occur.
